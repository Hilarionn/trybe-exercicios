# Meu repositório de exercícios

Este repositório reúne as atividades e os exercícios realizados por **Gabriel Hilarion** durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/). 🚀

Os conteúdos estão organizados por módulos e seções, acompanhando a progressão do currículo.

## Fundamentos do Desenvolvimento Web

### Unix, Shell & Git

Conteúdos sobre o sistema operacional Unix, comandos de Shell e ferramentas de controle de versão. Inclui navegação pelo terminal, gerenciamento de arquivos, Git e GitHub, repositórios, branches, commits e colaboração.

## Front-end

### HTML e CSS

Fundamentos para estruturar e estilizar páginas web com HTML e CSS. Inclui elementos e atributos HTML, seletores CSS, classes e IDs, posicionamento e organização de layouts

### JavaScript e DOM

Fundamentos de programação com JavaScript, incluindo variáveis, tipos de dados, operadores, estruturas condicionais, laços de repetição, funções, arrays e objetos. Introdução à interação com elementos HTML por meio do DOM

### HTML e CSS: Flexbox

Organização e alinhamento de elementos em páginas web com CSS Flexbox, utilizando contêineres e itens flexíveis para construir layouts

### Bibliotecas JavaScript

Uso de bibliotecas externas de JavaScript para ampliar funcionalidades e facilitar a implementação de recursos em páginas web
